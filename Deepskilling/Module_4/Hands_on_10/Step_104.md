# Inter-Service Communication

## Synchronous Communication

Advantages:
- Immediate response
- Easy implementation
- Simple debugging

Disadvantages:
- Tight coupling
- Service dependency
- Failure propagation

## Asynchronous Communication

Advantages:
- Loose coupling
- Better scalability
- Better fault tolerance

Disadvantages:
- More complex
- Eventual consistency

## RabbitMQ / Kafka Use Cases

Use message queues when:
- Sending emails
- Processing large workloads
- Event-driven systems
- High-volume communication
